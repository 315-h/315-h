OVERVIEW

项目概览

温柔陪伴、理性决策——一颗帮你把纠结讲清楚的星球

产品定位

多智能体 AI 决策辅助，结构化引导而非直接给答案。

核心价值

降低决策焦虑，把模糊的纠结拆成可衡量的选项。

我的角色

独立主导，从 0 到 1 定义形态与交互。

项目周期

2026 · 多轮迭代打磨体验。

我的角色：独立主导——需求采集卡 Schema 设计 · 四 Agent 架构定义 · 反事实代价预演卡交互 · 全场景知识库与测试体系搭建
PHILOSOPHY

设计理念

不替你做决定，只帮你把选择想得更清楚

场景化决策体系

覆盖 7 大高频生活场景，用结构化引导代替空洞建议——先理解你纠结的到底是什么，再陪你把每个选项的利弊摊开。

无性别平等设计

中立化话术，不预设用户身份，也不替用户做最终选择。所有输出保持克制——陪伴，而不是替代。

HOW IT WORKS

背后的实现 · 大白话

不用懂代码，也能看懂它是怎么工作的

四 Agent = 决策流程的四步

不是「四个机器人开会」，而是把「了解你 → 找方案 → 挑毛病 → 算代价」四个步骤用代码串起来，一步步走完，像一张流程图。
流程编排步骤化非黑盒

国产大模型驱动

决策分析由国产大模型（DeepSeek / 通义千问）完成，可本地部署、数据可控，不依赖外部黑盒服务。
DeepSeek通义千问本地可控

先查知识库，再回答

7 大场景的方案与测试集沉淀成知识库，AI 先检索再组织输出——结论有依据，不凭空发挥。
场景知识库先查后答可追溯

双端共用一套逻辑

小程序和网页版共用同一套后端决策流程（LangChain 手写状态机编排），写一次、跑两端，体验一致。
小程序 + 网页一套逻辑体验一致

ITERATION

迭代优化与体验升级

每一次迭代，都让决策收口更轻、更准

迭代前 · 记忆交互
  1. 直白调取历史记录
  2. 用户易有「被窥探感」
  3. 负面体验率偏高
→
迭代后 · 记忆交互
  1. 征询式引用历史
  2. 主动确认而非默认调取
  3. 负面体验率 < 5%
迭代前 · 反向纠偏
  1. 单点风险提示
  2. 用户常忽略盲点
  3. 触发率低
→
迭代后 · 反向纠偏
  1. 反事实预演卡片
  2. 把代价直接摊开
  3. 触发成功率 > 70%
迭代前 · 首页体验
  1. 信息杂乱堆砌
  2. 入口不清晰
  3. 决策收口慢
→
迭代后 · 首页体验
  1. 场景化入口
  2. 一眼找到纠结类型
  3. 决策收口效率提升
