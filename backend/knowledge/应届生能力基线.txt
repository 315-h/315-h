文件用途：应届生/转行人群能力评判简化标准，定义Agent在评估非经验丰富求职者时的校准规则。
================================================================================

========================================
应届生能力基线
========================================

---------
【核心原则】
---------

对应届生/转行人群的能力评判遵循以下原则：

1. 不要求实操指标：不因为缺少「操盘过百万预算」「管理过百万DAU产品」等硬性指标而降分
2. 看重学习速度：关注用户在短时间内掌握新知识和技能的速度
3. 看重项目完整度：关注用户是否完整经历过一个项目/任务的「从0到1」
4. 看重思维框架：关注用户是否具备岗位所需的基础思维框架和分析方法
5. 基础匹配项优先加权：在迁移评分时，与目标岗位基础能力要求匹配的项应优先获得较高权重

---------
【产品经理 - 应届生简化能力清单】
---------

■ 有则加分的能力项：
1. 有完整的产品分析/竞品分析报告（体现产品sense和分析能力）
2. 有原型设计作品（Axure/Figma/Sketch，体现设计能力）
3. 有课程项目中的需求分析/PRD撰写经历
4. 有互联网产品相关实习经历
5. 有个人产品体验博客/公众号（体现产品热情）

■ 可快速补齐的能力项：
1. PRD文档规范（学习1-2周可入门）
2. 原型工具操作（Axure基础功能1-2周可掌握）
3. 数据分析基础（了解核心指标概念1周可入门）
4. 敏捷开发流程（了解Scrum基本概念3天可入门）
5. SQL基础查询（学习2-3周可达到基础水平）

■ 替代证明方式：
- 没有产品实习 → 用课程项目中的产品分析报告/原型设计作品证明
- 没有PRD撰写经验 → 用自学产出的PRD文档或竞品分析报告证明
- 没有数据驱动经验 → 用课程中的数据作业或自学的数据分析项目证明
- 没有项目管理经验 → 用课程小组作业/竞赛项目的统筹经历证明
- 没有行业经验 → 用对目标行业的深度研究报告证明

---------
【产品运营 - 应届生简化能力清单】
---------

■ 有则加分的能力项：
1. 有社交媒体账号运营经历（公众号/小红书/抖音等）
2. 有校园活动策划和组织经历
3. 有社群运营/社区管理经验（社团、论坛、粉丝群等）
4. 有内容创作经历（文章、视频、设计作品等）
5. 有互联网运营相关实习经历

■ 可快速补齐的能力项：
1. 运营工具使用（各类运营后台1-2周可上手）
2. 用户分层逻辑（学习框架1周可入门）
3. 活动策划SOP（学习2-3周可入门）
4. 数据分析基础（运营数据分析1-2周可入门）
5. 内容分发策略（了解各平台规则1周可入门）

■ 替代证明方式：
- 没有用户运营经验 → 用社团管理/社群运营经历证明
- 没有内容运营经验 → 用个人自媒体账号/校园媒体运营证明
- 没有活动运营经验 → 用校园活动策划组织经历证明
- 没有数据分析经验 → 用课程数据作业/自学项目证明
- 没有增长运营经验 → 用社团招新/活动推广的实际效果证明

---------
【市场营销 - 应届生简化能力清单】
---------

■ 有则加分的能力项：
1. 有品牌/营销相关的竞赛获奖经历
2. 有自媒体内容创作和运营数据（粉丝数、阅读量等）
3. 有广告/传播/品牌策划类课程项目
4. 有市场营销相关实习经历
5. 有摄影/设计/视频剪辑等创意技能

■ 可快速补齐的能力项：
1. 广告投放平台基础操作（巨量引擎认证课程1-2周）
2. 品牌策略框架（学习经典模型1-2周）
3. 消费者调研方法（学习问卷设计和分析1-2周）
4. SEO/SEM基础（学习2-3周可入门）
5. 数据分析基础（营销数据分析1-2周可入门）

■ 替代证明方式：
- 没有品牌营销经验 → 用品牌策划竞赛/课程项目证明
- 没有投放经验 → 用广告平台认证证书/自学项目证明
- 没有市场调研经验 → 用课程调研项目/毕业论文的数据收集证明
- 没有预算管理经验 → 用社团活动预算/竞赛项目经费管理证明
- 没有创意产出经验 → 用个人作品集体现创意能力

---------
【人力资源 - 应届生简化能力清单】
---------

■ 有则加分的能力项：
1. 有人力资源/心理学/管理学相关课程背景
2. 有招聘/面试相关经历（校招志愿者、社团纳新负责人等）
3. 有培训/授课相关经历（家教、助教、内训分享等）
4. 有人力资源相关实习经历
5. 有HR相关证书（人力资源管理师、心理咨询师等）

■ 可快速补齐的能力项：
1. 招聘流程和方法（学习1-2周可入门）
2. JD撰写规范（学习3-5天可入门）
3. 面试方法基础（结构化面试学习1周可入门）
4. 劳动法基础知识（学习2-3周可入门）
5. 培训设计基础（学习ADDIE等模型1-2周可入门）

■ 替代证明方式：
- 没有招聘经验 → 用社团纳新/校招志愿者经历证明
- 没有HRBP经验 → 用学生会/社团中服务同学的经历证明
- 没有培训经验 → 用家教/助教/内训分享经历证明
- 没有绩效管理经验 → 用课程中的绩效管理模拟项目证明
- 没有员工关系经验 → 用社团中调解矛盾/组织活动的经历证明

---------
【数据分析 - 应届生简化能力清单】
---------

■ 有则加分的能力项：
1. 有SQL实战能力（能独立写复杂查询）
2. 有Python/R数据分析项目（含完整的数据处理和可视化）
3. 有统计学/计量经济学相关课程成绩优异
4. 有数学建模/数据分析类竞赛获奖
5. 有数据可视化作品（Tableau/Power BI看板作品）

■ 可快速补齐的能力项：
1. BI工具操作（Tableau/FineBI基础操作1-2周）
2. 业务指标理解（DAU/留存/转化等概念1周）
3. A/B测试基础流程（学习1-2周可入门）
4. 商业分析框架（学习MECE/波特五力等1-2周）
5. 数据报告撰写（学习1周可入门）

■ 替代证明方式：
- 没有业务分析经验 → 用课程数据项目/竞赛项目证明分析能力
- 没有报表搭建经验 → 用自学的BI看板作品集证明
- 没有A/B测试经验 → 用统计学课程中的实验设计作业证明
- 没有商业分析经验 → 用商业案例分析竞赛/课程论文证明
- 没有数据建模经验 → 用数学建模竞赛/课程项目证明

---------
【Agent评判校准规则】
---------

对应届生/转行人群进行能力评估时，Agent必须遵循以下校准规则：

1. 不因缺少实操指标降分
- 禁止因为候选人没有「操盘过XX项目」「管理过XX用户规模」等经验而直接降分
- 这些是经验维度的差异，不等于能力维度的不足

2. 重点关注三个维度
- 学习轨迹：是否有清晰的自学路径、学习成果和持续成长的证据
  - 加分信号：自学课程证书、个人项目、技术博客、持续学习的证据
- 项目完整度：是否完整经历过「发现问题→分析问题→解决问题→复盘总结」的全流程
  - 加分信号：课程项目、竞赛项目、毕业设计、个人项目中有完整链路
- 思维深度：回答问题时是否有框架感，能否从多角度分析问题
  - 加分信号：面试/简历中展现结构化思考、逻辑推导、数据佐证

3. 迁移评分加权规则
- 基础匹配项优先加权：与目标岗位「基础必备」能力匹配的项，给予1.2x权重加成
- 高阶加分项不降权：即使候选人没有实操经验，但展示出对高阶能力的理解和自学成果，仍应给予合理评分
- 软技能同等重要：应届生的软技能（沟通、结构化思考、自驱力等）应获得与硬技能相当的评分权重
- 迁移潜力加分：当候选人的过往经历与目标岗位存在能力桥梁时（参见《跨岗位通用能力对照表.txt》），应额外加5-10%的迁移潜力分

4. 典型误判防范
- 误判1：将「没有工作经验」等同于「没有能力」→ 应通过替代证明方式评估
- 误判2：将「课程项目」视为低价值经历 → 应关注项目的完整度和深度
- 误判3：将「非对口专业」视为劣势 → 应关注跨学科背景带来的差异化优势
- 误判4：将「短期实习」视为浅层经历 → 应关注实习中的具体贡献和学习收获
