========================================
能力缺口与成长路径
========================================

---------
【能力缺口判断逻辑】
---------

对用户的每项能力进行评估后，与目标岗位要求进行对比，计算差距分值（满分5分）：

| 差距大小 | 判断等级 | 含义 | 处理策略 |
|---------|---------|------|---------|
| 差距 > 3分 | 核心缺口 | 该能力严重不足，无法胜任目标岗位的基础要求 | 需系统学习，列入优先补齐计划 |
| 差距 1-3分 | 部分缺口 | 该能力有一定基础，但未达到目标岗位的理想水平 | 可针对性补强，通过项目实践快速提升 |
| 差距 = 0分 | 已具备 | 该能力已达到或超过目标岗位要求 | 可直接迁移，在简历和面试中重点展示 |

评分说明：
- 5分 = 3年以上/高级水平：能独立搭建体系/制定策略
- 4分 = 1-3年/中级水平：能独立负责完整模块
- 3分 = 应届生/初级水平的上限：能在指导下完成基础工作
- 2分 = 应届生/初级水平的中间：了解概念但缺乏实践
- 1分 = 有基本认知，几乎无实践
- 0分 = 完全匹配目标岗位的最低要求（注意：0分表示已达标，不是没有能力）

---------
【成长路径模板】
---------

■ 3个月速补计划（针对核心缺口和部分缺口）

适用场景：差距1-3分的部分缺口，需要在短期内快速补齐

第1个月：基础构建期
- 学什么：目标能力的核心概念、基础框架和基本方法
- 怎么学：
  - 系统学习1门在线课程（推荐类型：MOOC平台专业证书课程）
  - 阅读2-3本经典书籍/行业报告
  - 完成3-5个练手小项目
- 推荐资源类型：
  - 在线课程：Coursera/网易云课堂/极客时间/B站教程
  - 书籍：该领域入门经典教材
  - 实践：课程项目/自学项目/开源贡献

第2个月：实践深化期
- 学什么：将基础知识应用到实际场景，积累实操经验
- 怎么学：
  - 参与1-2个实战项目（实习/课程项目/竞赛/个人项目）
  - 寻找mentor或同行交流，获取反馈
  - 开始整理作品集/项目文档
- 推荐资源类型：
  - 实战平台：Kaggle/牛客网/LeetCode/实际业务项目
  - 社区：知乎/脉脉/行业社群/线下meetup
  - 反馈：找到mentor或加入学习小组

第3个月：成果沉淀期
- 学什么：将学习和实践成果系统化，形成可展示的作品集
- 怎么学：
  - 完成1个完整的端到端项目（从问题定义到成果交付）
  - 撰写项目复盘文档和方法论总结
  - 准备面试材料：将项目经历转化为简历和面试故事
- 验证方式：
  - 作品集完成度
  - 模拟面试表现
  - 实际面试反馈

■ 1年成长路径（针对核心缺口）

适用场景：差距>3分的核心缺口，需要系统性学习和长期积累

阶段一（第1-3个月）：基础构建 + 入门实践
- 目标：达到「应届生/初级」水平
- 里程碑：
  - 完成系统学习（课程+书籍）
  - 完成2-3个练手项目
  - 掌握基本工具和方法
- 验证方式：课程证书、项目作品集、基础技能测试

阶段二（第4-6个月）：专项突破 + 实战积累
- 目标：达到「初级上限」水平
- 里程碑：
  - 参与1-2个实战项目（实习/兼职/竞赛）
  - 在某一细分方向建立初步优势
  - 开始输出内容（博客/公众号/技术分享）
- 验证方式：实战项目成果、输出内容质量、同行认可

阶段三（第7-12个月）：体系化 + 独立负责
- 目标：接近「1-3年/中级」水平
- 里程碑：
  - 能独立负责完整项目/模块
  - 建立自己的方法论和工作流
  - 有可量化的成果指标
- 验证方式：独立项目成果、面试通过率、offer质量

---------
【按岗位的典型缺口→成长路径示例】
---------

■ 产品经理方向

典型缺口1：没有PRD撰写经验（常见于转行产品）
- 差距评估：通常2-3分（部分缺口）
- 3个月速补：
  - 第1月：学习PRD规范和模板，阅读优秀PRD案例（推荐：人人都是产品经理社区）
  - 第2月：选择2-3个熟悉的产品，独立撰写PRD（含需求分析、功能设计、交互说明）
  - 第3月：找产品经理朋友/mentor review，迭代优化，形成作品集
- 验证方式：3份完整PRD文档 + 对应原型设计

典型缺口2：缺乏数据分析能力（常见于文科背景转产品）
- 差距评估：通常2-3分（部分缺口）
- 3个月速补：
  - 第1月：学习SQL基础和数据分析思维（推荐：SQLZoo + 《精益数据分析》）
  - 第2月：用真实产品数据做一次完整的分析练习（如分析某App的转化漏斗）
  - 第3月：学习基础的数据可视化和报表制作
- 验证方式：SQL练习题 + 数据分析报告 + 数据看板截图

■ 产品运营方向

典型缺口1：没有用户运营实操经验（常见于应届生）
- 差距评估：通常2分（部分缺口）
- 3个月速补：
  - 第1月：学习用户运营方法论（AARRR模型、用户分层、生命周期管理）
  - 第2月：运营一个自己的社群（如学习群/兴趣群），实践拉新-促活-留存
  - 第3月：整理运营数据和复盘文档，形成案例集
- 验证方式：社群运营数据 + 运营策略文档 + 复盘报告

典型缺口2：缺乏活动策划经验（常见于转行运营）
- 差距评估：通常1-2分（部分缺口）
- 3个月速补：
  - 第1月：学习活动策划SOP，拆解10个优秀活动案例
  - 第2月：策划1个线上活动并执行（可为朋友/社群/学校策划）
  - 第3月：复盘活动效果，迭代活动方案
- 验证方式：活动方案文档 + 活动执行数据 + 复盘报告

■ 市场营销方向

典型缺口1：没有广告投放经验（常见于应届生/转行者）
- 差距评估：通常3-4分（核心缺口）
- 3个月速补：
  - 第1月：学习巨量引擎/腾讯广告基础操作（考取平台认证）
  - 第2月：用小预算（500-1000元）进行实际投放测试
  - 第3月：分析投放数据，优化投放策略，整理投放报告
- 验证方式：平台认证证书 + 投放数据报告 + 优化案例

■ 人力资源方向

典型缺口1：没有结构化面试经验（常见于转行HR）
- 差距评估：通常2-3分（部分缺口）
- 3个月速补：
  - 第1月：学习结构化面试方法（STAR法、行为面试法）
  - 第2月：参与模拟面试（为同学/朋友做模拟面试练习）
  - 第3月：整理面试评估模板和方法论文档
- 验证方式：面试评估模板 + 模拟面试记录 + 方法论文档

■ 数据分析方向

典型缺口1：SQL能力不足（常见于非技术背景转数据分析）
- 差距评估：通常3-4分（核心缺口）
- 3个月速补：
  - 第1月：系统学习SQL（推荐：SQLZoo + LeetCode SQL题 + Mode Analytics教程）
  - 第2月：每天练习2-3道SQL题，覆盖JOIN/子查询/窗口函数
  - 第3月：用真实数据集做完整的数据分析项目（从SQL查询到可视化报告）
- 验证方式：LeetCode SQL通过率 + 数据分析项目 + 可视化看板

典型缺口2：缺乏业务分析能力（常见于纯技术背景转商分）
- 差距评估：通常2-3分（部分缺口）
- 3个月速补：
  - 第1月：学习商业分析框架（MECE、波特五力、SWOT）+ 阅读行业报告
  - 第2月：选1-2个行业做深度研究，输出行业分析报告
  - 第3月：用数据验证商业假设，完成一份完整的商业分析报告
- 验证方式：行业分析报告 + 商业分析案例 + 数据支撑的商业建议

---------
【Agent使用指引】
---------

Agent在为用户生成能力缺口与成长路径时，应遵循以下步骤：

1. 评估用户各项能力得分（参照各岗位能力模型中的三级标准）
2. 与目标岗位要求对比，计算差距分值
3. 按差距大小分级：核心缺口（>3分）→ 部分缺口（1-3分）→ 已具备（0分）
4. 优先为「核心缺口」生成1年成长路径，为「部分缺口」生成3个月速补计划
5. 对「已具备」的能力，建议用户在简历和面试中重点展示
6. 参照上述典型缺口示例，结合用户具体背景定制成长方案
