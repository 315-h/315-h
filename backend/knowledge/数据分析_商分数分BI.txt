========================================
【数据分析 - 商业分析师】能力模型
========================================

【岗位定义】
通过数据分析和商业洞察，为公司的战略决策、业务增长和运营优化提供数据支撑。

---------
【核心能力项】
---------

1. 商业洞察与战略分析 【基础必备】
- 应届生/初级：能参与市场规模测算和竞品分析的基础数据收集与整理
- 1-3年/中级：独立完成商业分析项目，输出战略级分析洞察并推动决策
- 3年以上/高级：主导战略分析框架设计，建立商业洞察体系，成为核心决策智囊
- 典型场景：市场规模测算、竞争格局分析、商业模式评估、投资分析
- 关键指标：洞察采纳率、战略决策支撑度、分析报告质量

2. 业务诊断与问题拆解 【基础必备】
- 应届生/初级：能使用MECE等框架在指导下进行问题拆解，完成基础归因分析
- 1-3年/中级：独立将模糊的业务问题拆解为可分析的数据问题，精准定位原因
- 3年以上/高级：建立业务诊断方法论体系，快速识别复杂业务问题的核心矛盾
- 典型场景：业绩归因分析、增长瓶颈诊断、业务健康度评估
- 关键指标：问题定位准确率、分析周期、决策影响度

3. 数据建模与量化分析 【高阶加分】
- 应届生/初级：了解基本的统计和建模方法（回归、分类），能用Excel/Python做简单分析
- 1-3年/中级：独立运用统计和量化方法构建分析模型（用户分群、预测、因果推断）
- 3年以上/高级：主导复杂建模项目，建立量化分析方法论和模型治理体系
- 典型场景：用户分群模型、预测模型、因果推断、定价模型
- 关键指标：模型准确率、模型业务价值、方法论严谨度

4. 数据呈现与沟通影响 【基础必备】
- 应届生/初级：能制作基础数据图表和分析报告，清晰展示数据结论
- 1-3年/中级：独立将复杂分析结论以清晰方式传达给决策者，推动决策采纳
- 3年以上/高级：建立数据沟通和汇报体系，高效影响高层决策
- 典型场景：管理层汇报PPT、数据看板设计、跨部门沟通
- 关键指标：汇报采纳率、沟通效率、利益相关者满意度
- 注：汇报表达、沟通协作等通用能力参见《软实力通用能力.txt》

5. 行业研究与市场洞察 【高阶加分】
- 应届生/初级：能收集整理行业数据和信息，参与行业研究报告撰写
- 1-3年/中级：独立完成行业趋势分析和前瞻性市场洞察报告
- 3年以上/高级：建立行业研究体系，持续提供战略性市场前瞻判断
- 典型场景：行业趋势报告、竞品分析、新兴机会识别
- 关键指标：报告影响力、预判准确率、信息及时性

---------
【常见面试问题】
---------
- 初级：某产品DAU下降了，如何分析原因？如何做用户分群？
- 中级：如何评估一个新业务的市场机会？举一个你通过数据推动业务决策的案例
- 高级：如何建立商业分析体系？如何影响高层战略决策？

---------
【能力迁移关键词】
---------

========================================
【数据分析 - 数据分析师】能力模型
========================================

【岗位定义】
负责日常业务数据分析、报表搭建和数据工具建设，为业务团队提供数据支持和分析服务。

---------
【核心能力项】
---------

1. SQL与数据查询 【基础必备】
- 应届生/初级：掌握SQL基础语法（SELECT/JOIN/GROUP BY），能完成简单的数据查询
- 1-3年/中级：精通复杂SQL编写，能高效处理多表关联、窗口函数和性能优化
- 3年以上/高级：主导数据查询架构设计，建立SQL规范和查询优化体系
- 典型场景：复杂SQL编写、多表关联查询、窗口函数应用、性能优化
- 关键指标：查询效率、数据准确率、需求响应速度

2. 报表与数据看板 【基础必备】
- 应届生/初级：能使用BI工具（如Tableau/FineBI）制作基础数据报表
- 1-3年/中级：独立搭建业务数据报表和可视化看板，实现数据自动化
- 3年以上/高级：主导企业级数据看板和指标体系建设
- 典型场景：日报/周报/月报设计、BI看板搭建、数据自动化
- 关键指标：报表覆盖率、数据准确率、看板使用率

3. 统计分析与A/B测试 【基础必备】
- 应届生/初级：了解基本统计学概念（均值、中位数、标准差、p值），能参与A/B测试数据收集
- 1-3年/中级：独立完成A/B测试全流程设计与分析（样本量计算、假设检验、结果解读），掌握相关性分析和回归分析
- 3年以上/高级：建立实验分析方法论体系，设计复杂实验方案（多变量、长期效应），推动组织实验文化建设
- A/B测试核心步骤：①明确假设 → ②计算样本量 → ③随机分组 → ④执行实验 → ⑤收集数据 → ⑥统计检验 → ⑦结果解读与决策
- 典型场景：A/B测试分析、相关性分析、回归分析、假设检验
- 关键指标：结论可靠性、方法论规范性、分析深度

4. 业务分析与专题研究 【基础必备】
- 应届生/初级：能在指导下完成基础业务数据分析，整理分析结论
- 1-3年/中级：独立针对具体业务问题开展专题分析，提出可执行建议
- 3年以上/高级：主导重大业务专题研究，建立分析框架和方法论沉淀
- 典型场景：用户行为分析、转化漏斗分析、异常值排查、趋势分析
- 关键指标：分析深度、业务方满意度、建议可执行性

5. 数据工具与效率提升 【高阶加分】
- 应届生/初级：了解Python/R基础语法，能做简单的数据处理
- 1-3年/中级：独立运用Python/R进行数据处理和分析自动化
- 3年以上/高级：主导数据工具链建设，建立分析模板和工具复用体系
- 典型场景：数据自动化脚本、Python数据处理、分析报告模板化
- 关键指标：自动化覆盖率、分析效率提升比、工具复用度

---------
【常见面试问题】
---------
- 初级：写一个SQL：求每个部门工资最高的前3名。如何向非技术人员解释p值？
- 中级：如何设计一个A/B测试？如何处理数据中的异常值？
- 高级：如何建立数据分析方法论体系？如何推动组织数据文化？

---------
【能力迁移关键词】
---------
SQL [硬技能]、数据查询 [硬技能]、报表搭建 [硬技能]、统计分析 [硬技能]、A/B测试 [硬技能]、数据可视化 [硬技能]、Python [硬技能]、业务分析 [硬技能]

========================================
【数据分析 - BI分析师】能力模型
========================================

【岗位定义】
负责企业级BI体系建设、数据平台搭建和数据产品化，让数据真正服务于业务决策。

---------
【核心能力项】
---------

1. 数据仓库与建模 【基础必备】
- 应届生/初级：了解数据仓库基本概念和分层架构（ODS/DWD/DWS/ADS）
- 1-3年/中级：独立进行维度建模和ETL设计，保证模型复用度和查询性能
- 3年以上/高级：主导数据仓库架构设计和数据分层规范制定
- 典型场景：维度建模、数据分层设计、ETL流程设计
- 关键指标：模型复用度、数据质量、查询性能

2. BI工具与平台建设 【基础必备】
- 应届生/初级：能使用1-2种主流BI工具（Tableau/Power BI/FineBI）制作报表
- 1-3年/中级：独立搭建企业级BI平台和自助分析平台
- 3年以上/高级：主导BI平台战略规划，构建数据中台和分析生态
- 典型场景：Tableau/Power BI/FineBI平台搭建、自助分析平台建设
- 关键指标：平台覆盖率、用户活跃度、自助分析率

3. 数据治理与质量管理 【高阶加分】
- 应届生/初级：了解数据治理基本概念和数据质量维度
- 1-3年/中级：独立建立数据标准和质量管控体系
- 3年以上/高级：主导企业级数据治理战略，建立数据资产管理框架
- 典型场景：数据标准制定、数据质量监控、元数据管理
- 关键指标：数据质量得分、标准覆盖率、问题闭环率

4. 需求管理与数据服务 【基础必备】
- 应届生/初级：能参与数据需求的登记和基础评估
- 1-3年/中级：独立管理数据需求，提供高效的数据服务并维护SLA
- 3年以上/高级：建立数据服务体系和需求优先级决策框架
- 典型场景：需求评估、数据服务SLA管理、数据需求优先级排序
- 关键指标：需求响应时效、需求满足率、服务满意度

5. 数据产品化思维 【高阶加分】
- 应届生/初级：了解数据产品化基本概念，能参与数据字典的基础维护
- 1-3年/中级：独立将数据能力产品化，搭建指标体系和数据字典
- 3年以上/高级：主导数据产品战略，降低全员数据使用门槛
- 典型场景：数据产品设计、指标体系搭建、数据字典维护
- 关键指标：数据产品使用率、自助化率、用户满意度

---------
【常见面试问题】
---------
- 初级：维度建模和范式建模有什么区别？常用的BI工具有哪些？
- 中级：如何搭建企业级BI体系？如何设计一套指标体系？
- 高级：如何保证数据质量？如何制定数据治理战略？
